# 视频生成说明

## 成片规格

- 时长：08:10.73
- 画面：1920 × 1080，30 fps，H.264
- 音频：AAC，48 kHz，单声道，192 kbps
- 场景顺序与时长：读取 `asset_manifest.json`
- 本地成片：`C:\disk\self-space\self-media\交易体系复盘_8分钟成片_v1.mp4`

## 动画设计

- 所有分镜使用幅度约 2% 的缓慢推近与轻微横向移动。
- 相邻画面使用 0.6 秒交叉淡化，成片总时长不因转场缩短。
- 真实账户页依次强调近一年收益、同期比较和视频主旨。
- 三年页依次强调累计收益、风险指标和样本限制。
- 当前组合页依次强调组合指标、中证500指标和曲线区域。
- 六个月页依次强调五套策略的收益与回撤卡片，再回到整体曲线。
- 策略分工页和体系原则页跟随旁白顺序逐项强调。

## 重新生成

```powershell
python render_video.py <audio.wav> <output.mp4> --encoder qsv
```

生成加速版时使用：

```powershell
python render_video.py <audio.wav> <output.mp4> --encoder qsv --speed 1.15
```

脚本会同时压缩画面时间轴并使用 `atempo` 加速语音，保持原音调。

Intel 核显不可用时，可改用 `--encoder x264`。生成后应检查总时长、完整解码、转场帧和各场景代表帧。
